字民 ZIMIN — Macao Visual Archive
==================================

這個資料夾就是整份網站，不需要伺服器、不需要安裝任何東西。

怎麼開
------
1. 先「解壓縮」（對 zip 按右鍵 → 全部解壓縮）。不要在壓縮包裡面直接點。
2. 進入解壓出來的資料夾，雙擊 index.html（建議 Chrome / Edge）

如果你看到白屏
--------------
新版會在畫面上直接寫出原因，通常是這兩種：

· 「3 秒過去，畫面仍然是空的」→ 你是從壓縮包裡直接打開的，先解壓縮。
· 整頁有版面，但每張圖都是粉紅色「圖檔遺失」→ img/ 資料夾沒跟著複製過去。

還是不行，就雙擊 如果打不開_用這個.cmd：
它會在本機開一個小伺服器，然後用瀏覽器打開 http://127.0.0.1:8787/
（只用 Windows 內建的 PowerShell，不用安裝東西）

為什麼可以直接開
----------------
· index.html 已經把程式與樣式全部內嵌（約 450 KB），單獨一個檔就能跑
· 圖片用相對路徑，跟著資料夾走
· 路由用 #/index 這種 hash，不用伺服器改寫
· 所以整包複製到任何位置、丟進 USB、上傳到靜態空間都能跑

要放到網路上
------------
把整個資料夾上傳到任何靜態空間即可：
· GitHub Pages（放進 repo 根目錄）
· Netlify / Vercel（直接拖曳資料夾）
· 學校的 www 空間

因為是 hash 路由，不需要任何 rewrite 規則。
